# 🌦️ MoodyCast

MoodyCast is a fun weather web app that combines real-time weather data with moods, relationship status, age groups, outfit suggestions, extra advice, and GIF-based vibes.

Instead of only showing weather information, MoodyCast tells users how the weather *feels* emotionally 😄

---

## ✨ Features

-  Search weather by city
- Real-time weather information
- Mood-based vibe generation
- Relationship-based suggestions
- Outfit recommendations
- Extra advice system
- Dynamic GIF integration using GIPHY API
- Fully responsive design
- Modern glassmorphism UI

---

## 🚀 Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- OpenWeatherMap API
- GIPHY API
